# ☕ Mocha Café

A clean, responsive, and accessible website of **Mocha Café**, an artisanal coffee shop located in **C-Scheme, Jaipur**.

Built purely with **HTML5** and **Tailwind CSS**. It automatically supports dark mode based on your device settings (`prefers-color-scheme`).

---

## 📄 Pages Included

1. **Home (`index.html`)**
   - Hero section with brand introduction and call-to-action buttons
   - Coffee highlights strip (single-origin, micro-roasting, bakery, garden)
   - "Why Choose Us" section using Flexbox
   - Customer testimonials using CSS Grid
   - Weekly business hours and location strip

2. **Menu & Pricing (`menu.html`)**
   - Espresso bar, manual pour-overs, cold brews, and fresh bakery items
   - Card-based layout using CSS Grid
   - Pricing table for take-home whole-bean coffee bags

3. **Gallery (`gallery.html`)**
   - Responsive photo grid showcasing café ambiance, roastery equipment, and pastries
   - Descriptive alt text on all images for accessibility

4. **Contact & Reservations (`contact.html`)**
   - Accessible table reservation form with linked labels and proper input types
   - Café address, phone, email, and opening hours
   - Embedded Google Map of C-Scheme, Jaipur

---

## 🛠️ Tech Stack & Design

- **HTML5**: Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **Tailwind CSS**: Utility-first styling with zero inline styles
- **Fonts**: Playfair Display (headings) & Plus Jakarta Sans (body)
- **Theme**: Coffee-inspired color palette (`mocha`, `cream`, `amber`)
- **Dark Mode**: Automatic `prefers-color-scheme` support
- **Responsive**: Fully optimized for mobile, tablet, and desktop screens

---

## 🚀 How to Run Locally

1. Clone or open the project folder in your editor.
2. Open `index.html` in any web browser, or use VS Code Live Server.
