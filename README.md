# ☕ Mocha Café — Jaipur

A café based in C-Scheme, Jaipur.

---

## 📋 Project Overview
- **Project Type**: Milestone 1 Project — Web Foundation (Full Stack + AI Engineering)
- **Selected Track**: **Option A — Local Business Website**
- **Business Identity**: Mocha Café
- **Tech Stack**: HTML5, Tailwind CSS, Google Fonts (`Playfair Display` & `Plus Jakarta Sans`)
- **Theme**: Warm Coffee, Espresso, Rich Mocha, and Cream

---

## 🗂️ Required Pages (4 Pages)
1. **Home (`index.html`)**: Brand hero with primary CTAs, roast highlights, "Why Choose Us" Flexbox section, customer testimonials, and weekly business hours strip.
2. **Menu (`menu.html`)**: Signature espresso bar, cold brews, artisan bakery, and gourmet breakfast cards organized with CSS Grid, dietary tags, and pricing.
3. **Gallery (`gallery.html`)**: Responsive visual showcase of Jaipur courtyard seating, barista pour-over bar, specialty beans, and warm interior ambiance.
4. **Contact & Reservations (`contact.html`)**: 100% accessible table reservation and query form (`label` linked to `id`, proper input types), Jaipur address details, and an embedded Google Map.
